### 👋 안녕하세요, 이민욱입니다.

저는 **문제를 기술로 해결하는 데 진심인 개발자**입니다.
불편한 사용자 경험을 발견하면 직접 해결하고자 기획하고, 때로는 팀을 이끌어 서비스로 만들어 왔습니다.

현재는 **크로스플랫폼 앱 개발자**를 목표로, React Native를 중심으로 한 모바일 앱과 Spring Boot 기반의 백엔드 개발 역량을 함께 키워가고 있습니다.

### 🌱 이런 개발자로 성장 중입니다
- 기능보다 **문제 해결을 중심에 두는 개발자**
- 사용자 흐름과 피드백을 고려한 **실전형 제품 개발 경험 보유**
- 팀 내 협업과 커뮤니케이션에도 적극적으로 참여하며 **문제를 함께 풀어가는 개발자**로 성장하고 있습니다.
